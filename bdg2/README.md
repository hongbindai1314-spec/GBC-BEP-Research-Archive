# BDG2 Research Benchmark

This folder is a synthetic reconstruction of the author-reported six-site/90-building experiment. It is **not** the canonical selected BDG2 subset and synthetic IDs (e.g., `S00_B001`) must not be described as official BDG2 building IDs.

Included: six site manifests totaling 90 buildings; 2016-2017 hourly electricity and weather; site-specific Jul-Dec 2017 origin audits; full scalar 24-hour multi-horizon prediction exports; and site-level metric checks against the manuscript targets.
